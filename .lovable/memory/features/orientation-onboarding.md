---
name: Orientation onboarding
description: First sign-in Eastern/Oriental/Undecided sticker and tradition defaults
type: feature
---
First sign-in sticker: Eastern (blue), Oriental (orange, then pick which Oriental church), Undecided (grey, leave app as is).
Choice sets profile branch, History island tab, Saints/Prayers tradition filters. Settings has an Eastern/Oriental/Undecided default.
Branch → icon style: Coptic→Coptic, Ethiopian/Eritrean Tewahedo→Tewahedo, Russian→Russian, Greek→Greek; any other leaves icons unchanged. Same applies when branch changes on the profile card.
